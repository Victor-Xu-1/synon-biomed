## Image rules / 图片规范

- Put a visible concept label beside generated artwork, not only in alt text.
- Use real application captures for UI, execution and result images.
- Do not generate messages, metrics, task status, outputs or success evidence.
- Record capture revision/date and meaningful form interactions.
- Use consented, non-sensitive data; label demonstration data.
- Keep raw test logs and private capture evidence outside the product repository.
- Preserve copyright and provenance for third-party assets; an integrity hash
  is not a rights grant.

真实界面和结果必须来自实际运行，不用概念图或重新绘制的界面冒充截图。
